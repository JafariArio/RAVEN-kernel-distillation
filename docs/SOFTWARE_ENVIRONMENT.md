# RAVEN software environment and dependencies

## MATLAB
RAVEN was prepared and tested using MATLAB R2026a.

## Required MATLAB toolbox
- Statistics and Machine Learning Toolbox

## Optional MATLAB toolbox
- Parallel Computing Toolbox

The Parallel Computing Toolbox can accelerate supported operations but is not required for the core RAVEN workflow. RAVEN can fall back to serial execution.

## Operating system
The publication release was tested under Microsoft Windows 10/11.

## External dependencies
RAVEN does not require Python, R, CUDA, external executables, or undocumented third-party MATLAB packages.

## Hardware
No specialized GPU hardware is required. CPU count and system memory can affect execution time for larger datasets.

## Release
- Software release: RAVEN v1.0.0
- MATLAB release: R2026a

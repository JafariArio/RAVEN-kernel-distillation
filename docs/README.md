# RAVEN documentation

This directory contains the public text documentation for RAVEN v1.0.0.

- `USER_MANUAL.md` — GUI workflow and operational guide
- `REPRODUCIBILITY_GUIDE.md` — representative reproduction workflow
- `DATA_FORMAT.md` — accepted inputs
- `CONFIGURATION_REFERENCE.md` — configuration reference
- `EXPECTED_OUTPUTS.md` — expected output structure
- `SOFTWARE_ENVIRONMENT.md` — MATLAB/toolbox requirements
- `DATASET_PROVENANCE_AND_LICENSING.md` — third-party dataset provenance and redistribution policy
- `GITHUB_ZENODO_WORKFLOW.md` — archival release workflow

The journal manuscript and Supporting Information are intentionally not included in this software repository.

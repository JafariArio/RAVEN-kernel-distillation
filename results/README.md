# Publication result packages

The full locked Dataset A, Dataset B, and Dataset C publication-result trees are intentionally maintained outside the Git source repository.

Reasons include:

- avoiding unnecessary large binary development/result files in Git;
- preventing accidental redistribution of third-party biological data or derived files with unclear redistribution rights;
- preserving the exact locked publication result packages as separate archival objects.

This repository includes a compact representative output set under `examples/reference_outputs/`.

The final Zenodo/GitHub release metadata should link to any separately archived publication-result package if one is deposited.

RAVEN_V1_01 modular source package

Run from MATLAB:

    RAVEN_V1_01

Main launcher:

    RAVEN_V1_01.m

Editable GUI source modules:

    RAVEN_core/source_modules

MATLAB builds the runnable nested-function core automatically at launch:

    RAVEN_core/RAVEN_V1_01_core.m

After editing any module, run RAVEN_V1_01 again. The launcher rebuilds the core when source modules are newer than the generated core.
